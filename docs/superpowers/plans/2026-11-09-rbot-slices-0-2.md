# RBOT slices 0–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the RBOT repo with its gates, then deliver two live-proven slices. Slice 1 runs CP-0 on a TDG case folder through `gh copilot` into a styled `report.html`. Slice 2 adds CP-1 with Python-computed ratios that match final-workflow's TDG figures.

**Architecture:** `rbot run <case> --out <dir>` extracts every source into per-page text files and runs the pathway's modules in order. Each module is one `gh copilot` call per attempt, limited to read-only tools inside the case's work folder. RBOT validates the returned Markdown handoff (sections, citations, verbatim quotes) and retries up to 3 times with the findings. Python calculators turn a module's JSON block into computed figures. A static renderer writes one offline HTML file with no JavaScript.

**Tech Stack:** Python 3.13, uv 0.12.5, pypdf, stdlib (`decimal`, `html.parser`, `zipfile`, `xml.etree`, `subprocess`), pytest, hypothesis, ruff, mypy strict.

## Global Constraints

- Python `>=3.13,<3.14`; uv `==0.12.5`; package `rbot` under `src/rbot/`; console script `rbot = "rbot.__main__:main"`.
- Runtime dependencies in slices 0–2: `pypdf` only (pin the version FWPY pins: `pypdf==6.21.2`). Any other runtime dependency needs a decision record in `docs/decisions/`.
- Every file copied from FW or FWPY gets a row in `tools/copied-from.txt` (format in Task 0.3). Copies keep their behaviour; trims are listed as `edited`.
- Text I/O is always `encoding="utf-8"` and `newline="\n"` for writes. Paths use `pathlib`. Renames use `os.replace`. No POSIX-only calls. Both `macos-latest` and `windows-latest` must pass.
- No stub or fake value stands in for real behaviour in `src/`. The fake `gh` exists only under `tests/`.
- No catch-all `except` that hides a failure, unless the fail-open is documented in a comment and logged in `run.log`.
- An answer key or oracle under `tests/oracles/` is written by the controller. Implementers never edit it or loosen the comparison against it.
- Every task report ends with a `Not verified:` line.
- Model default `auto` with `--auto-tier intelligence` and no `--reasoning-effort` (ruling 2026-11-09: this Copilot account rejects every explicit `--model`, and `auto` rejects an effort flag; see docs/copilot-cli.md). Env `RBOT_MODEL` set to a specific model passes `--model <m>` and, if `RBOT_EFFORT` is set, `--reasoning-effort <e>` instead of the auto tier. `run.log` records the routed model from the events (`session.auto_mode_resolved.chosenModel`, else `assistant.message.model`). Up to 3 attempts per module, on validation failures only. Call timeout 1,800 s. `--max-ai-credits` per call from `RBOT_MAX_CREDITS`, default `100`.
- Handoff H2 sections, in this order and spelled exactly: `## Request`, `## Sources`, `## Findings`, `## Calculations`, `## Gaps`, `## Next module`.
- Citation form: `[<source file name> p.<N>]`, where N is 1-based.
- Report CSP, exactly: `default-src 'none'; style-src 'unsafe-inline'; font-src data:; img-src data:; script-src 'none'; base-uri 'none'; form-action 'none'`.
- Gates (all exit 0): `uv run ruff check`, `uv run ruff format --check`, `uv run mypy`, `uv run pytest --cov=rbot --cov-fail-under=80`, `uv run complexipy src --max-complexity-allowed 15`, `uv run bandit -r src -q`, `uv run pip-audit --strict`, `uv lock --check`, `npx --yes jscpd@4 --threshold 3 src`, `gitleaks git`, `python tools/suppressions.py`, `python tools/pr_size.py --base origin/main`.

## Review Focus

1. **Long prompts on Windows.** A prompt that includes upstream handoffs can exceed Windows' 32,767-character command line. Expected: the prompt is written to a file and `-p` carries only a short pointer. Pinned by `test_long_prompt_goes_to_file` (Task 1.2).
2. **The model escapes the case folder.** A handoff whose run tried to read outside `work/<case>/`, or to write anything at all, must not be accepted. Expected: tools are limited to the probe's read-only list, the working directory is the case, and any write or shell event in the stream fails the attempt. Pinned by `test_write_tool_event_fails_attempt` (Task 1.2).
3. **Model-written HTML in the report.** A handoff containing `<script>`, `<img onerror>`, `javascript:` links or `</style>` must render as text. Pinned by `test_markdown_escapes_html` (Task 1.5).
4. **Quotes that look verbatim but are not.** Curly vs straight quotes, non-breaking spaces, hyphenation or line-wrapping from layout-mode PDF text. Expected: normalisation equates those, and a changed word still fails. Pinned by `test_quote_normalisation` (Task 1.3).
5. **An interrupted run is resumed.** Expected: accepted modules are skipped when their fingerprint is unchanged, and a module whose inputs changed reruns. Pinned by `test_resume_skips_accepted_module` (Task 1.4).
